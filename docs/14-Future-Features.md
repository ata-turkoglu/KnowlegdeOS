# Future Features

## Built-in OCR

İleride ChatGPT yerine yerel OCR pipeline eklenebilir.

Örnek:

- Tesseract
- PaddleOCR
- EasyOCR
- local vision model

## DOCX Import

Word dosyalarından Markdown üretme.

## PDF Import

PDF içinden görüntü ve metin çıkarma.

## Obsidian Export

Workspace'i Obsidian vault olarak dışa aktarma.

## Desktop App

Tauri veya Electron ile paketleme.

## Portable Mode

USB diskten çalışabilecek taşınabilir sürüm.

## Advanced Knowledge Graph

Daha gelişmiş ilişki grafiği.

## Citation by Page/Line

Sayfa ve satır bazlı kaynak gösterme.

## Manual Annotation

Belge içinde entity işaretleme.

## Model Benchmark

Farklı LLM ve embedding modellerini aynı test setinde karşılaştırma.
